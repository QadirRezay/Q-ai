# بخش رابط کاربری (Frontend UI) - دستیار هوشمند کدنویسی

این پوشه شامل طراحی، ظاهر و رنگ‌بندی (تم تیره مخصوص برنامه‌نویسان) برای اتصال به سرور FastAPI است.

## محتویات
- `index.html`: ساختار اصلی صفحه چت، منوی انتخاب زبان برنامه‌نویسی و شناسه گفتگو.
- `style.css`: رنگ‌بندی تیره (Dark Mode)، چیدمان راست‌به‌چپ برای فارسی و چپ‌به‌راست برای بلوک‌های کد.
- `script.js`: اتصال به سرور (`http://127.0.0.1:8000`)، رنگ‌بندی خودکار کدها، دکمه کپی و دانلود نوت‌پد و PDF.

## نحوه اجرا
1. این پوشه را در کنار پوشه `backend` در پروژه خود قرار دهید.
2. ابتدا سرور پایتون (`uvicorn app.main:app --reload`) را روشن کنید.
3. فایل `index.html` را در مرورگر باز کنید (یا با افزونه Live Server در VS Code اجرا نمایید).
