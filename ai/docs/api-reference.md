# مرجع فنی مسیرهای سرور (API Reference)

## ۱. ارسال درخواست کدنویسی (`POST /chat`)
**بدنه درخواست (JSON):**
```json
{
  "session_id": "project_1",
  "prompt": "یک تابع برای مرتب‌سازی لیست بنویس",
  "language": "Python"
}
```

## ۲. دانلود خروجی نوت‌پد (`POST /export/notepad`)
خروجی این مسیر یک فایل با پسوند `.txt` و کدگذاری `UTF-8` است که شامل کد خالص بدون توضیحات اضافی می‌باشد.

## ۳. دانلود خروجی PDF (`POST /export/pdf`)
خروجی این مسیر یک فایل `.pdf` با فونت استاندارد برنامه‌نویسی (`Courier`) است.
