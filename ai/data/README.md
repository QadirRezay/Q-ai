# پوشه نگهداری پایگاه داده (Data)

این پوشه محل ذخیره‌سازی خودکار فایل پایگاه داده حافظه گفتگوها (`chat_history.db`) است.

## نکات مهم:
- به محض اجرای سرور (`uvicorn app.main:app --reload`)، فایل `chat_history.db` به‌صورت خودکار در این مسیر ساخته می‌شود.
- برای حفظ حریم خصوصی و امنیت داده‌ها، فایل‌های با پسوند `.db` در فایل `.gitignore` قرار گرفته‌اند تا به گیت‌هاب آپلود نشوند.
- فایل `.gitkeep` باعث می‌شود ساختار پوشه `data` در مخزن گیت‌هاب شما حفظ شود.
